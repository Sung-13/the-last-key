# The Last Key — project memory

iOS app called **The Last Key** — helps the user memorise English sentences/expressions (with Korean meanings) as a 2–3 minute morning ritual. Frontend-only, SwiftUI + SwiftData, iOS 17+, no backend, no cloud, no analytics.

## Current state (as of 2026-07-16)

**Fully smoke-tested and visually redesigned.** The app now uses the "Dawn Warm" design language: warm cream background (`DawnBackground`), amber→coral sunrise gradient on primary buttons and the Today hero card, rounded typography, warm charcoal dark mode. All design tokens live in `TheLastKey/TheLastKey/Theme.swift` (colors are asset-catalog sets with light+dark variants: DawnBackground, DawnSurface, DawnAmber, DawnAmberDeep, DawnCoral, AccentColor). **App icon (2026-07-16): painterly layered-band "K"** (Werner Bronkhorst-inspired) generated by `tools/make_icon.swift` (run: `swift tools/make_icon.swift TheLastKey/TheLastKey/Assets.xcassets/AppIcon.appiconset`) — 7 wavy overlapping paint bands, deterministic SplitMix64-seeded geometry (re-runs are byte-identical), light = cream + sunrise ramp, dark = charcoal + hand-picked embers ramp (blending toward charcoal went muddy olive — don't), tinted = monochrome white-alpha per Apple spec.

**Habit streak + Home Screen widget (2026-07-16):** `PracticeDay` @Model (unique startOfDay date + sessionsCompleted) records each day a session is completed. Recording fires in `PracticeView.grade` at the `queue.isDone` transition — exactly once per session; do NOT move it to the completion view's `.onAppear` (re-fires on re-render). `StreakCalculator` (in `TheLastKey/Shared/`, compiled into app + widget) treats an unfinished today as pending: the streak only breaks after the day is over. `StreakView` renders the flame counter + 15-week GitHub-style squares grid on Today. The widget (`TheLastKeyWidget` extension target, small + medium) reads a mirror of the completed-day list from App Group UserDefaults (`group.com.sung13.TheLastKey`, written by `StreakRecorder.mirrorToWidget` after each completion and on app foreground via ContentView's scenePhase) and recomputes the streak per timeline entry (now + next midnight); the SwiftData store itself is NOT shared — keep it that way. Widget colors are hex literals (extensions can't see the app's asset catalog).

Verification status: BUILD SUCCEEDED; 35 unit tests pass (8 `cue` + 9 `keywordCue` + 6 PracticeQueue + 9 StreakCalculator + 3 StreakRecorder); UI smoke suite `TheLastKeyUITests/SmokeScreenshotTests` passes in light and dark mode and covers: seed → Today → session → reveal → grade (asserts the missed card re-queues within the session), streak card shows "practiced today" after the session, Library add/search/delete, empty-library CTA → add sheet with autofocus, Settings. SwiftData test gotcha: keep the `ModelContainer` alive for the whole test body — a `ModelContext` does not retain its container and using it after the container deallocates traps (EXC_BREAKPOINT).

**Keyword cloze + readability (2026-07-16):** practice cards hide only key words (`ClozeFormatter.keywordCue`); card text is proportional rounded (no more monospace), blanks are amber with a small kern, and the Korean meaning is `.title2` semibold as the recall prompt. **Navigation gotcha fixed the hard way:** TodayView originally pushed practice via `navigationDestination(isPresented:)` + a `session` @State array — a @Query update mid-session (every grade saves) could spontaneously pop and re-push the destination, resetting the PracticeQueue (caught on video via the smoke suite's screen recording). Now uses `navigationDestination(item:)` with the Identifiable `PracticeRoute` wrapper (stable UUID identity) in `TodayView.swift` — do not revert to the isPresented pattern.

Xcode project at `TheLastKey/TheLastKey.xcodeproj`, **Xcode 16 format with `PBXFileSystemSynchronizedRootGroup`** — any `.swift` file dropped into `TheLastKey/TheLastKey/` (app), `TheLastKey/Shared/` (app + widget), `TheLastKey/TheLastKeyWidget/` (widget), `TheLastKey/TheLastKeyTests/`, or `TheLastKey/TheLastKeyUITests/` is automatically a member of that target. Build settings still require explicit `project.pbxproj` edits. Deployment target iOS 17.0. **4 targets**: app, widget extension, unit tests, UI tests. `TheLastKey/Config/` (entitlements ×2 + widget Info.plist) is deliberately OUTSIDE all Xcode groups — sync groups would copy them as resources / collide with the generated Info.plist; build settings reference them by SRCROOT-relative path. The widget target must NOT get `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` (clashes with nonisolated TimelineProvider). Simulator builds carry App Group entitlements in `*-Simulated.xcent` with FAKETEAMID (`codesign -d --entitlements` shows an empty dict — that's normal on simulator); on a physical device both targets need the user's DEVELOPMENT_TEAM (App Groups work on free personal teams).

Build: `xcodebuild -project TheLastKey/TheLastKey.xcodeproj -scheme TheLastKey -destination 'platform=iOS Simulator,name=iPhone 17' build`. Newest simulator on this machine is iPhone 17 (iOS 26.5); `iPhone 16` is NOT installed. Bundle ID is `com.sung13.TheLastKey`.

**Running the UI smoke tests with correct appearance:** `xcodebuild test -only-testing:TheLastKeyUITests/SmokeScreenshotTests -parallel-testing-enabled NO` — parallel testing must be OFF, otherwise tests run on a cloned simulator that ignores `simctl ui <udid> appearance dark` and discards data mutations. Boot the device (`simctl boot`) *before* `simctl ui … appearance …`; the command fails with "Unable to lookup in current state: Shutdown" on a shut-down device. Screenshots are XCTAttachments — export with `xcrun xcresulttool export attachments --path <xcresult> --output-path <dir>` (writing files from the test runner to host paths is sandbox-blocked). Note the suite mutates data (deletes/re-adds entries); `simctl uninstall` + reinstall restores the first-launch seed.

**TTS-on-simulator gotcha:** if `▶ Listen` plays nothing on the iOS Simulator, check (a) Mac system volume isn't muted, (b) Simulator menu → **Device → Audio Output** is set to a real output (not "None"). TTS output itself still needs human ears on hardware — XCUITest can't assert audio.

## Confirmed product decisions (do not re-litigate)

| Area | Decision |
|---|---|
| App name | The Last Key |
| Memorisation technique | First-letter cueing on **key words only** + audio (iOS TTS). Content words get `b___`-style cues; function words stay visible (stopword list in `ClozeFormatter.keywordCue`, all-stopword sentences fall back to full cueing). Changed from all-word cueing 2026-07-16 at user request. |
| Unit of study | Full sentences (or shorter expressions) — not separate "phrase + example" |
| Daily session size | 5 cards (configurable 3–15 in Settings) |
| Session ordering | `Review again` first → unseen → least-recently-seen |
| In-session re-queue (2026-07-16) | "Review again" sends the card to the back of *today's* stack until remembered once; it stays flagged for a future session regardless (`PracticeQueue`) |
| Visual direction (2026-07-16) | "Dawn Warm": cream/amber/coral sunrise palette, rounded type, warm charcoal dark mode — chosen by user over Ink & Paper / Midnight Gold / Fresh & Playful |
| App icon (2026-07-16) | Painterly layered paint-stroke bands (Werner Bronkhorst-inspired) with a bold white "K", Dawn Warm palette — user chose this over Bronkhorst blues / sunset-with-dark-contrast |
| Habit streak (2026-07-16) | User explicitly requested streak tracking (reverses the earlier "no streaks" non-goal). GitHub-style squares grid + flame counter on Today — chosen over month calendar |
| Morning-start mechanism (2026-07-16) | Home Screen widget (streak + today's done/not-done) — user chose this over local morning notification and Shortcuts App Intent. A completed day = the daily session finished (all cards cleared) |
| Alarm automation (2026-07-31) | Shortcuts personal automation "Alarm Is Stopped → Open App" with **zero app code** — user chose this over adding an App Intent that auto-starts the session. Works because cold launch lands on Today (`selectedTab` defaults `.today`). Auto-start deep link (App Intent + lifting `selectedTab`/`practiceRoute` into a shared router) deliberately deferred. Setup guide: `/Users/sungkyungkim/.claude/plans/user-to-set-up-scalable-graham.md` |
| Input | Manual entry in-app only |
| Storage | Local on-device only — SwiftData |
| Platform | iPhone, iOS 17+, SwiftUI, SwiftData, AVFoundation. Zero external dependencies. |

## Explicit out-of-scope (non-goals)

- Backend / cloud sync / iCloud
- Accounts, analytics, third-party services
- Bulk or CSV import
- Points/leaderboard-style gamification (the streak + squares grid IS in scope since 2026-07-16; charts beyond it are not)
- AI-generated examples or translations
- Push notifications (remote). Local notifications were offered 2026-07-16 and the user chose the widget instead
